(async) loginIntegration()

Inicializa el detector de eventos de envío del formulario de inicio de sesión. Esta función intercepta el envío del formulario, envía las credenciales de inicio de sesión al backend y almacena el token JWT si el inicio de sesión es exitoso. En caso de éxito o fracaso, se muestran las notificaciones correspondientes al usuario.
